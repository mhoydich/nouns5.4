PROMISE.JS

Write mapWithLimit(items, limit, worker).

The harness supplies a positive integer limit. Return a promise for an array of results that follows four rules:

  1. Bounded: never have more than limit worker calls active.
  2. Complete: call worker(item, index) once for every item.
  3. Ordered: resolve results in input order, even when workers finish out of order.
  4. Honest: reject with the original error, stop starting new work, and never mutate the input.
Open three hints No point penalty

Create a result array and a shared next index. Start at most limit async lanes. Each lane claims an index, awaits the worker, and writes into that index. A shared failed flag closes the gate.

EXAMPLE await mapWithLimit(["slow", "fast"], 2, worker)
// fast may finish first
→ ["SLOW", "FAST"]
