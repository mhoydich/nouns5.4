Repair the
release order.

READY 00 POINTS / 100
CONTRACT.JS

Write repairQueue(records).

Return an array of release IDs that follows four rules:

  1. Current: for each id, keep only the record with the highest numeric revision.
  2. Active: remove an ID when its current record has cancelled: true.
  3. Ordered: higher priority first; ties use the earliest createdAt.
  4. Careful: do not mutate the input array or its records.
Open three hints No point penalty

Use a Map keyed by ID. Replace its value only when a larger revision arrives. Filter the current values, sort a new array, then map to IDs.

EXAMPLE [{ id: "beta", revision: 1, priority: 5 },
{ id: "alpha", revision: 2, priority: 8 }]
→ ["alpha", "beta"]
