    03 / STUDENT WALLET RULES

    Spend after the brief gets specific.

    A subscription is not progress. Buy the next constraint only when the artifact tells you what is missing.

    1. 01
      Claim student doors first.

      Check the current GitHub Education pack and campus licenses while you still have verified eligibility.

    2. 02
      Use test modes before live modes.

      Fake data, verified recipients, sandbox payments, and preview deployments are enough for the first proof.

    3. 03
      Set a hard ceiling.

      Write the weekly credit or API budget before the first generation. Turn on usage alerts where the service offers them.

    4. 04
      Keep a no-subscription version.

      Your brief, source list, code, edit decisions, and receipt should survive if every paid service disappears tomorrow.
