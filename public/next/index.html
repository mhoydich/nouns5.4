How it evolves.

  1. Ship one small public instrument at a time, each with a real output—not a concept page.
  2. Let PointCast distribute the result and report what actually reaches people.
  3. Add Passport only when identity makes the experience richer; add Tezos only when ownership or settlement is genuinely useful.
  4. Promote repeated, loved behavior into a focused project site. Retire experiments that do not earn another version.
  5. Keep a visible trail from experiment → publication → identity → world, so the sites form a circuit instead of competing homepages.
