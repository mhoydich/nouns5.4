The opening

Group chats do not need more content.
They need a reason to happen now.

Tag puts one live object in the room: a person, a prompt, and a clock. It is a social excuse with just enough structure to make a moment—not another feed.

The loop

One tag creates the whole game.

  1. 1Choose

    Tag one person.

  2. 2Dare

    Photo, voice, song, or a tiny mission.

  3. 3Prove

    Drop it before the clock runs out.

  4. 4Pass

    The tagged person becomes It.

  5. 5Keep

    The round becomes a group recap.

Every answer creates the next invitation.

Version 0.1

Build the smallest version people can restart.

  • 4–12 people
  • One active tag
  • Photo / text / voice
  • Timer + pass
  • Five mood packs
  • End-of-round recap

Start where the ritual works

The first build can be mobile web with a shareable room link. Native Messages integration is a later test—not a blocker to learning whether the relay is fun.

No follower graph
No public feed
No infinite scroll

The build

Four weeks. One public finish.

  1. 01Feel

    Prototype the handoff. Choose the interaction grammar.

  2. 02Work

    Room, timer, media, prompt packs, pass.

  3. 03Play

    Run three groups. Fix friction. Build recap.

  4. 04Release

    Public demo, source, test notes, next call.

Deliverable → mobile prototype + source + test notes + public artifact
