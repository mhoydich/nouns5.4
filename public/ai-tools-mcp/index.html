00 / THE TWO LAYERS

The model is not
the connection.

A strong model can reason about what you give it. An MCP server can expose a new source or action. Adding a server changes the permission boundary, not the model’s intelligence.

AI TOOL

A place to think, code, or make.

ChatGPT, Claude, Codex, Cursor, Figma Make, and Runway are work surfaces. Choose one for its fit with the artifact and the review loop.

Question: what should exist when the session ends?
MCP SERVER

A bridge to context or action.

GitHub, Figma, Sentry, Playwright, and documentation servers let an agent inspect or act beyond its starting context. Each bridge needs a scope and a stop rule.

Question: what may the agent read or change?

      04 / BEFORE CONNECT

      Pass the
      permission gate.

      MCP makes the agent more capable because it changes what the agent can reach. Treat every server like a new collaborator entering the room.

      1. 01
        Name the receipt.

        Install for one concrete outcome, not because a connector exists.

      2. 02
        Verify the publisher.

        Use the official product docs or publisher repository. Registry presence alone is not enough.

      3. 03
        Inventory every tool.

        Know what can read, navigate, create, edit, delete, submit, or send.

      4. 04
        Reduce the scope.

        Prefer one project, one repository, test data, read-only mode, and project-local configuration.

      5. 05
        Run a harmless test.

        List tools, perform one read, inspect the returned source, and confirm no mutation occurred.

      6. 06
        Keep a stop rule.

        Require human approval for writes, messages, purchases, deployments, and irreversible actions.

      05 / A SAFE FIRST MCP

      Start with
      documentation.

      OpenAI’s public Docs MCP is remote, read-only, and documentation-only. It is a good way to learn the connection loop before adding account data or write tools.

      CODEX / TERMINALOFFICIAL OPENAI SERVER
      codex mcp add openaiDeveloperDocs --url https://developers.openai.com/mcp
codex mcp list

      Then ask for one current doc page and inspect the source it returns.
